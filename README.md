## إضافة مقال جديد

1. انسخ `articles/_template.html` وسمّ النسخة باسم إنجليزي قصير، مثل `articles/sweden-new-law.html`.
2. استبدل فيها كل: `SLUG` (اسم الملف بدون .html)، والعنوان، والوصف، والتاريخ (بصيغة 2026-01-31 داخل الكود)، والتصنيف، والنص.
3. ضع صورة المقال في `images/` بنفس الاسم، مثل `images/sweden-new-law.jpg`.
4. في `index.html` انسخ أول بطاقة `<a class="card" ...>` في قسم «كتاباتي» والصقها في أعلى الشبكة، ثم عدّل الرابط والعنوان والتاريخ والتصنيف والصورة.
5. أضف سطراً للمقال في `sitemap.xml`.
